Level 6: Functions in C

What are Functions?

A function is a block of code that performs a specific task. Functions help in code reusability, modularity, and readability.

In C, there are two types of functions:

  • Library Functions – Built-in functions like printf(), scanf(), sqrt(), etc.
  • User-defined Functions – Functions created by the programmer.

Syntax of a Function

C has three categories of control statements:

A function typically has:

  • A return type (what it returns)
  • A name (identifier)
  • Parameters (optional inputs)
  • A body (statements)
  • A return statement (if applicable)

            returnType functionName(parameters) {
                // Function body
                return value; // Optional
            }

Declaring and Calling a Function

A function must be declared before use.

Example: Function to Add Two Numbers

            #include 

                // Function declaration (prototype)
                int add(int, int);
                
                int main() {
                    int result = add(5, 3); // Function call
                    printf("Sum: %d", result);
                    return 0;
                }
                
                // Function definition
                int add(int a, int b) {
                    return a + b; // Return sum
                }

Output

            Sum: 8

Types of User-Defined Functions

Functions with No Return and No Parameters

Performs an action but does not return a value.

Example: Print a Greeting

            #include 

                void greet() {
                    printf("Hello, welcome to C programming!\n");
                }
                
                int main() {
                    greet(); // Function call
                    return 0;
                }

Output

            Hello, welcome to C programming!

Output

            1 2 3 4 5

Functions with No Return but with Parameters

Takes input but does not return a value..

Example: Print Sum of Two Numbers

            #include 

                void printSum(int a, int b) {
                    printf("Sum: %d\n", a + b);
                }
                
                int main() {
                    printSum(4, 7); // Function call
                    return 0;
                }

Output

 
            Sum: 11

Functions with Return but No Parameters

Returns a value but takes no input.

Example: Return a Number

            #include 

                int getNumber() {
                    return 10;
                }
                
                int main() {
                    int num = getNumber();
                    printf("Number: %d", num);
                    return 0;
                }

output

            Number: 10

Functions with Return and Parameters

Takes input and returns a value.

Example: Multiply Two Numbers

            #include 

                int multiply(int a, int b) {
                    return a * b;
                }
                
                int main() {
                    int result = multiply(6, 5);
                    printf("Multiplication: %d", result);
                    return 0;
                }

Output:

            Multiplication: 30

Function Prototypes (Declaration)

  1. Function prototypes allow functions to be used before their actual definition.
  2. Placed at the beginning of the program.

Example

            #include 

                void display(); // Function prototype
                
                int main() {
                    display(); // Function call
                    return 0;
                }
                
                void display() {
                    printf("This is a function prototype example.");
                }

Recursive Functions

  1. A function that calls itself.
  2. Used for problems like factorial, Fibonacci, etc.

Example: Factorial using Recursion

            #include 

                int factorial(int n) {
                    if (n == 0)
                        return 1;
                    return n * factorial(n - 1);
                }
                
                int main() {
                    printf("Factorial of 5: %d", factorial(5));
                    return 0;
                }

Output

                Factorial of 5: 120

Passing Arguments to Functions

Call by Value (Default in C)

  • Passes a copy of the variable.
  • Changes inside the function do not affect the original value.

Example

                #include 

                    void changeValue(int x) {
                        x = 100; // Changing x does not affect main()
                    }
                    
                    int main() {
                        int num = 50;
                        changeValue(num);
                        printf("Value: %d", num);
                        return 0;
                    }

Output

                Value: 50

Call by Reference (Using Pointers)

  1. Passes the memory address.
  2. Changes inside the function affect the original value.

Example

                #include 

                    void changeValue(int *x) {
                        *x = 100; // Changes the original value
                    }
                    
                    int main() {
                        int num = 50;
                        changeValue(&num);
                        printf("Value: %d", num);
                        return 0;
                    }

Output

                Value: 100
