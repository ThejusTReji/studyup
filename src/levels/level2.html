Level 2: Data Types and Variables

What are Data Types?

A data type in C determines the type of data a variable can store. It defines the memory size, format, and range of values.

Data TypeSizeDescriptionExample
int4 byteInteger numberint num = 10;
float4 byteFloating-point numbers (decimal)float pi = 3.14;
double8 byteDouble-precision floating-pointdouble d = 3.141592;
char1 byteSingle characterchar ch = 'A';

Declaring Variables in C

A variable is a container for storing data.

Syntax:

            data_type variable_name = value;

Example:

            int age = 25;
            float temperature = 36.5;
            char grade = 'A';

Multiple Variable Declaration

            int x, y, z;  // Declares multiple integer variables
            float a = 5.6, b = 3.2;

Rules for Naming Variables

  • Variable names must start with a letter or underscore (_).
  • They cannot contain spaces or special characters.
  • They cannot be a C keyword (e.g., int, return).
  • They are case-sensitive (Age and age are different).

Valid Examples:

            int age;
            float price123;
            char _grade;

Invalid Examples:

 
            int 123number;  // Starts with a number (❌)
            float price$;   // Special character not allowed (❌)
            char return;    // Uses a keyword (❌)

Constants in C

A constant is a variable whose value cannot be changed.

Declaring Constants using const Keyword

            const float PI = 3.1416;
            const int DAYS_IN_WEEK = 7;

Example:

            #include 

                int main() {
                    const float PI = 3.1416;
                    printf("The value of PI is: %.4f\n", PI);
                    return 0;
                }

Note: If you try to modify PI, the compiler will show an error.

Basic Input and Output with Different Data Types

We use scanf() to take input and printf() to display output.

Example: Taking Different Data Type Inputs

            #include 

                int main() {
                    int num;
                    float price;
                    char grade;
                
                    printf("Enter an integer: ");
                    scanf("%d", &num);
                
                    printf("Enter a float: ");
                    scanf("%f", &price);
                
                    printf("Enter a character: ");
                    scanf(" %c", &grade); // Space before %c to remove newline character
                
                    printf("Integer: %d, Float: %.2f, Character: %c\n", num, price, grade);
                    return 0;
                }

Type Conversion in C

1. Implicit Type Conversion (Automatic)

The compiler automatically converts smaller data types into larger ones.

            int num = 10;
            float result = num + 2.5;  // 'num' is converted to float automatically

2. Explicit Type Conversion (Casting)

We manually convert one type to another using type casting. 

            float num = 10.75;
            int result = (int) num;  // Explicitly converting float to int
            printf("%d", result);  // Output: 10

Memory Sizes of Data Types

You can use the sizeof operator to check the size of a data type.

Example:

#include 

            int main() {
                printf("Size of int: %lu bytes\n", sizeof(int));
                printf("Size of float: %lu bytes\n", sizeof(float));
                printf("Size of char: %lu byte\n", sizeof(char));
                printf("Size of double: %lu bytes\n", sizeof(double));
                return 0;
            }
            
        
Expected Output:

        
            Size of int: 4 bytes
            Size of float: 4 bytes
            Size of char: 1 byte
            Size of double: 8 bytes
