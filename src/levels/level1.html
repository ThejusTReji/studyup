Level 1: Introduction to C Programming

Overview of C Programming

C is a powerful, general-purpose programming language that is widely used for system programming, embedded systems, and application development. It is known for its efficiency, portability, and flexibility.

Structure of a C Program

A basic C program consists of:

    1. Preprocessor Directives: #include ()
    2. Main Function: int main() { ... }
    3. Statements and Functions
    4. Return Statement

Example: Hello, World! Program

            #include  // Standard Input and Output Library

                int main() {  
                    printf("Hello, World!\n");  // Print a message
                    return 0;  
                }

Explanation:

    #include : Includes the standard I/O library.
    int main(): The entry point of the program.
    printf(): Prints output to the screen.
    return 0;: Indicates successful execution.

The printf() function is used to display output on the screen.

            printf("format string", arguments);

            printf("The value of x is %d\n", 10);

Using scanf() for Input

The scanf() function is used to take input from the user.

Example: Taking an integer input

            int age;
            printf("Enter your age: ");
            scanf("%d", &age);  // Takes user input
            printf("You entered: %d\n", age);

Key Points:

  • & (Address-of operator) is required for variables in scanf().
  • The format specifier in scanf() must match the variable type.

Example: Taking multiple inputs

            int num;
            float price;
            printf("Enter an integer and a float: ");
            scanf("%d %f", &num, &price);
            printf("You entered %d and %.2f\n", num, price);
