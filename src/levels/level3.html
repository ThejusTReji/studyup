Level 3: Operations and Expressions in C

What are Operators?

Operators are symbols that perform operations on variables and values.

Example:

            int sum = 10 + 5;  // Here, '+' is an operator

Types of Operators in C

1. Arithmetic Operators

These operators perform basic mathematical operations.

OperatorDescriptionExample
+Additiona+b
-Subtractiona-b
*Multiplicationa*b
/Divisiona/b
%Modulus(Remainder)a%b

Example:

                #include 

                int main() {
                    int a = 10, b = 3;
                    printf("Addition: %d\n", a + b);
                    printf("Subtraction: %d\n", a - b);
                    printf("Multiplication: %d\n", a * b);
                    printf("Division: %d\n", a / b);
                    printf("Modulus: %d\n", a % b);
                    return 0;
                }

Output:

            Addition: 13  
            Subtraction: 7  
            Multiplication: 30  
            Division: 3  
            Modulus: 1

Note: In integer division (/), the decimal part is ignored.

2. Relational (Comparison) Operators

These operators compare values and return 1 (true) or 0 (false).

0 (false)
OperatorMeaningExample(a=5,b=10)Result
==Equal toa == b
!=Not Equal toa != b1 (true)
>Greater thana > b0 (false)
<Less thana < b 1 (true)
>=Greater than or equal toa >= b0 (false)
<=Less than or equal toa <= b1 (true)

Example:

            #include <.stdio.h>

                int main() {
                    int a = 5, b = 10;
                    printf("%d\n", a > b);  // Output: 0 (false)
                    printf("%d\n", a < b);  // Output: 1 (true)
                    return 0;
                }

3. Logical Operators

Used for combining multiple conditions.

OperatorMeaningExample(a=5,b=10)Result
&&AND(a > 0 && b > 0)1 (true)
' ' OR
!NOT!(a > b)1 (true)

Example:

 
            #include 

                int main() {
                    int a = 5, b = 10;
                    printf("%d\n", (a > 0 && b > 0)); // Output: 1 (true)
                    printf("%d\n", (a < 0 || b > 0)); // Output: 1 (true)
                    printf("%d\n", !(a > b)); // Output: 1 (true)
                    return 0;
                }

4. Assignment Operators

Used to assign values to variables.

OperatorExample(a=5,b=10)Result
=a = bAssign b to a
+=a += 5a = a + 5
-=a -= 2a = a - 2
*=a *= 3a = a * 3
/=a /= 4a = a / 4
%=a %= 2a = a % 2

Example:

            #include 

                int main() {
                    int x = 10;
                    x += 5;  // x = x + 5
                    printf("%d", x);  // Output: 15
                    return 0;
                }

5. Increment and Decrement Operators

These operators increase or decrease a value by 1.

OperatorMeaningExample
++Increment by 1a++ or ++a
--Decrement by 1a-- or --a

Example:

            int x = 5;
            printf("%d\n", x++);  // Output: 5 (Post-increment)
            printf("%d\n", ++x);  // Output: 7 (Pre-increment)

Expressions in C

Expressions combine variables, values, and operators.

Examples of Expressions

            int result = (5 + 2) * 3;  // Result: 21
            int x = 10, y = 5;
            int sum = x + y;           // Sum: 15
