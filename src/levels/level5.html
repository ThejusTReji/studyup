Level 5: Control Statements in C

1. What are Control Statements?

Control statements in C control the flow of execution based on conditions or loops.

These statements help manage:

  • Looping (Iteration) → Execute code multiple times
  • Jumping (Branching) → Transfer control to another part of the program

Types of Conditional Statements in C

C has three categories of control statements:

A) Looping Statements

  • for loop
  • while loop
  • do-while loop

B) Jumping Statements

  • break statement
  • continue statement
  • goto statement
  • return statement

Looping Statements

Looping is used to repeat a block of code until a condition is met.

The for Loop

  • Used when the number of iterations is known.
  • Consists of initialization, condition, and increment/decrement.

Syntax

            for (initialization; condition; update) {
                // Code to execute
            }

Example: Print numbers 1 to 5

            #include <.stdio.h>

                int main() {
                    for (int i = 1; i <= 5; i++) {
                        printf("%d ", i);
                    }
                    return 0;
                }

Output:

            1 2 3 4 5

The while Loop

  • Used when the number of iterations is unknown.
  • Runs while the condition is true.

Syntax

            while (condition) {
                // Code to execute
            }

Example: Print numbers 1 to 5

            #include <.stdio.h>

                int main() {
                    int i = 1;
                    while (i <= 5) {
                        printf("%d ", i);
                        i++;
                    }
                    return 0;
                }

Output

            1 2 3 4 5

3.The do-while Loop

Similar to while, but runs at least once, even if the condition is false.

Syntax

            do {
                // Code to execute
            } while (condition);

Example: Print numbers 1 to 5

 
            #include 

                int main() {
                    int i = 1;
                    do {
                        printf("%d ", i);
                        i++;
                    } while (i <= 5);
                    return 0;
                }

Output:

            1 2 3 4 5

4. Jumping Statements

Jumping statements alter the normal execution flow./p>

The break Statement

Exits a loop or switch statement immediately.

Example: Stop loop at 3

            #include 

            int main() {
                for (int i = 1; i <= 5; i++) {
                    if (i == 3) {
                        break;
                    }
                    printf("%d ", i);
                }
                return 0;
            }

output

            1 2

The continue Statement

Skips the rest of the current iteration and moves to the next iteration.

Example: Skip 3

            #include 

                int main() {
                    for (int i = 1; i <= 5; i++) {
                        if (i == 3) {
                            continue;
                        }
                        printf("%d ", i);
                    }
                    return 0;
                }

Output:

            1 2 4 5

The goto Statement

Jumps to a labeled statement. (⚠️ Not recommended for structured programming.)

Syntax

            goto label;
            // Some code
            label:

Example:

            #include 

                int main() {
                    int num = 2;
                    
                    if (num < 5) {
                        goto skip;
                    }
                
                    printf("This will be skipped.\n");
                
                skip:
                    printf("Jumped here using goto.\n");
                
                    return 0;
                }

Output

            Jumped here using goto.

The return Statement

Exits a function and returns a value.

Example

            #include 

            int add(int a, int b) {
                return a + b;
            }
            
            int main() {
                int result = add(5, 3);
                printf("Sum: %d", result);
                return 0;
            }

Output

                Sum: 8

Common Mistakes in Loops and Jumping Statements

  • 🚫 Infinite Loops: Forgetting to update the loop variable.
  • 🚫 Incorrect use of break and continue: Misplacing them can lead to unexpected behavior.
  • 🚫 Using goto: Makes the code hard to understand.
