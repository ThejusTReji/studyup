Level 4: Conditional Statements in C

What are Conditional Statements?

Conditional statements allow a program to make decisions based on conditions.

Example:

            if (age >= 18) {
                printf("You can vote.");
            } else {
                printf("You cannot vote.");
            }

Types of Conditional Statements in C

C provides several conditional statements:

  • if statement
  • if-else statement
  • if-else if-else statement
  • Nested if statement
  • switch statement
  • Ternary (? :) operator

1. The if Statement

The if statement executes a block of code only if the condition is true.

Syntax

            if (condition) {
                // Code executes if condition is true
            }

Example:

            #include <.stdio.h>

                int main() {
                    int num = 10;
                    if (num > 0) {
                        printf("Number is positive.\n");
                    }
                    return 0;
                }

Output:

            Number is positive.

2. The if-else Statement

The if-else statement provides an alternative block if the condition is false.

Syntax

            if (condition) {
                // Executes if condition is true
            } else {
                // Executes if condition is false
            }

Example:

            #include <.stdio.h>

                int main() {
                    int num = -5;
                    if (num >= 0) {
                        printf("Number is positive.\n");
                    } else {
                        printf("Number is negative.\n");
                    }
                    return 0;
                }

3.The if-else if-else Statement

When there are multiple conditions, we use if-else if-else.

Syntax

            if (condition1) {
                // Executes if condition1 is true
            } else if (condition2) {
                // Executes if condition2 is true
            } else {
                // Executes if none of the conditions are true
            }

Example: Checking Grades

 
            #include 

                int main() {
                    int marks = 85;
                    
                    if (marks >= 90) {
                        printf("Grade: A\n");
                    } else if (marks >= 80) {
                        printf("Grade: B\n");
                    } else if (marks >= 70) {
                        printf("Grade: C\n");
                    } else {
                        printf("Grade: F\n");
                    }
                
                    return 0;
                }

Output:

            Grade: B

4.Nested if Statement

An if statement inside another if statement is called a nested if.

Syntax

if (condition1) {
            // Executes if condition1 is true
        } if (condition2) {
            // Executes if condition2 is true
        } else {
            // Executes if none of the conditions are true
        }

Example:

            #include <.stdio.h>

                int main() {
                    int num = 5;
                
                    if (num > 0) {
                        if (num % 2 == 0) {
                            printf("Number is even.\n");
                        } else {
                            printf("Number is odd.\n");
                        }
                    }
                
                    return 0;
                }

Output

                Number is odd.

5. The switch Statement

The switch statement is used when we have multiple choices.

Syntax

            switch (expression) {
                case value1:
                    // Code for value1
                    break;
                case value2:
                    // Code for value2
                    break;
                default:
                    // Code if no cases match
            }

Example: Menu System

            #include 

                int main() {
                    int choice;
                    
                    printf("Enter a number (1-3): ");
                    scanf("%d", &choice);
                    
                    switch (choice) {
                        case 1:
                            printf("You selected 1.\n");
                            break;
                        case 2:
                            printf("You selected 2.\n");
                            break;
                        case 3:
                            printf("You selected 3.\n");
                            break;
                        default:
                            printf("Invalid choice.\n");
                    }
                
                    return 0;
                }

Input: 2

Output:

                You selected 2.

Notes: ✅ The break statement stops execution after a case. ✅ The default case executes when no case matches.

6.The Ternary (? :) Operator

The ternary operator is a shorthand for if-else.

Syntax

            condition ? expression1 : expression2;

Example:

            #include 

                int main() {
                    int num = 10;
                    (num % 2 == 0) ? printf("Even\n") : printf("Odd\n");
                    return 0;
                }

Output

            Even

Common Mistakes in Conditional Statements

  • 🚫 Forgetting break in switch statements (causes fall-through).
  • 🚫 Not using {} for multiple statements in if.
  • 🚫 Using = instead of == in conditions (if (x = 5) instead of if (x == 5)).
